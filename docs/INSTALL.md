# Chrome へのインストール

このフォークは Chrome 向けリリースを対象にします。Firefox 版は元の Nyaa Enhancer プロジェクトの範囲であり、このフォークではサポート対象としていません。

## 展開版を読み込む

1. GitHub Releases から Chrome 用 ZIP をダウンロードします。
2. ZIP を新しいフォルダーへすべて展開します。
3. 展開したフォルダーを開き、直下に `manifest.json` があることを確認します。`src/chrome` のような親フォルダーや、ZIP 内にさらに一段あるフォルダーは選びません。
4. Chrome で `chrome://extensions` を開きます。
5. 右上の「デベロッパー モード」をオンにします。
6. 「パッケージ化されていない拡張機能を読み込む」を選び、手順 3 のフォルダーを選択します。
7. 拡張機能カードにエラーがなく表示され、ツールバーの拡張機能メニューから有効になっていることを確認します。

v1.16.1から `sukebei.nyaa.si` も起動対象です。更新後は拡張機能を再読み込みし、すでに開いている対象サイトのページも再読み込みしてください。Chromeが追加サイトへのアクセス確認を表示した場合は、Sukebeiを対象とする権限を確認してください。

更新するときは、まず新しいZIPを一時フォルダーへ展開します。現在読み込んでいる拡張フォルダーのファイルを新しい版で置き換え、Chromeの拡張機能カードで「再読み込み」を押してください。同じフォルダーパスを使うことで拡張IDと設定を維持します。別の場所へ移す場合は別IDになることがあるため、更新とは分けて扱ってください。

v1.17.0から初期表示が日本語です。**表示言語** は一覧上部・拡張ポップアップ・設定画面にあります。**日本語 / English** を選ぶと保存され、操作した画面だけ再読み込みします。ほかの開いているタブでは、次の再読み込み時に反映されます。

v1.18.0から、対象サイトを開いていない場合もポップアップの設定リンクで拡張内の設定画面を開けます。サイト上と同じ保存設定を使用し、保存失敗を成功扱いにしません。

元の Nyaa Enhancer は、この改造版と同時に有効にしないでください。元版の設定は自動移行されません。ストア経由の自動更新はありません。

リリースZIPには、直下の `manifest.json`、`LICENSE.txt`、`MODIFICATIONS.md`、`THIRD_PARTY_NOTICES.txt` と `SOURCE.txt` が入ります。対応するソースZIPは同じリリースにあります。

実サイトでの動作確認は実行環境のサイト安全ポリシーにより未実施です。ローカル検証の内容と範囲は [QA記録](QA.md) を参照してください。
