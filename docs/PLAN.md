# 実装計画

この文書は、2026-09-13に合意したフォーク方針です。実装は本リポジトリ、検証結果は [QA記録](QA.md)、配布物はGitHub Releasesを参照してください。

## 目的

元リポジトリのGitHub Forkとして `came815/nyaa-enhancer-presets` を公開し、フォーク名を **Nyaa Enhancer Presets** とする。公開対象は Chrome 向けの新しいリリースと対応するソースであり、元プロジェクトの Firefox 版をこのフォークがサポートするとは表明しない。

## 検索プリセット

- Day: 24 時間
- Week: 7 日間
- Month: 30 日間（既定値）
- 3Month: 90 日間
- Year: 365 日間

各プリセットは、検索開始時点で固定した相対アップロード時刻を基準にする。結果はシーダー数の降順で並べる。

## 追加読み込み

検索結果は一度に全期間を取得することを保証しない。`Show more` は取得済みの結果の後へ増分で追加し、進捗を表示する。処理中はキャンセルでき、キャンセル後は同じ検索条件で再開できるようにする。

2026-09-13の追加合意: 自動読み込み・状態表示・期間選択欄の固定表示を追加する。末尾の約600px手前から自動で読み込み、オン・オフ操作は保存する。通信エラーやアクセス制限、タイムアウト、10ページ連続で該当結果がない場合は明示的な再開を待つ。非表示のタブでは新しい取得を始めない。戻る操作での読み込み位置復元などは、この更新には含めない。

## 状態の扱い

選択した期間、検索開始時刻、検索語・カテゴリ、並び順はURLに保持する。Show moreの取得進行位置はページ内だけに保持し、再読み込み時はURLに示す開始ページから表示し直す。URL に保持されることは、対象期間の全結果が取得済みである保証ではない。

## リリース方針

- Chrome 向けの展開用 ZIP は、展開後に選ぶフォルダー直下に `manifest.json` がある構成にする。
- 同じリリースで対応するソースを提供する。
- `LICENSE.txt`、元プロジェクトへの帰属、変更内容、および同梱物のライセンス表記を保持する。

## 実装後に予定する検証

実装完了後に、Chrome での展開版読み込み、各期間の境界と既定値、検索開始時刻の固定、シーダー降順、追加読み込みの進捗・キャンセル・再開、URL からの条件復元を確認する。リリース ZIP の展開先直下に `manifest.json`、`LICENSE.txt`、帰属情報が含まれることも確認する。
