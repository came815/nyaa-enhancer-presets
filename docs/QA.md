# QA記録 — v1.17.0

検証日: 2026-09-14。この更新も **Pre-release** とします。

結果: 単体テスト **11/11 合格**、ブラウザテスト **22/22 合格（2.4分）**。日本語の一覧・設定・ポップアップと、英語1920px / 日本語390pxのダウンロード進捗画像を目視確認しました。

v1.17.0では日本語 / Englishの切り替えと一括ファイル取得のキャンセルを追加しました。ブラウザテストは引き続きlocalhost上で実行し、架空の一覧・ファイル応答で確認します。Sukebei実サイト上での起動・速度を直接測定した結果ではありません。

## 確認環境と範囲

- Windows、Node.js 24、Playwright 1.63.0 の Chromium。
- 自動ブラウザ検証は、実装したChrome拡張のコピーを一時プロファイルへ読み込み、許可先を一覧テストでは `127.0.0.1:4174`、ファイル取得テストでは `127.0.0.1:4175` だけに置き換えて実施します。機能コードは配布版と同じです。
- v1.16.0の手動表示確認はGoogle Chromeの `127.0.0.1:4173`。ページから同じ機能コードを読み込み、Chrome storage/runtime APIだけ検証用スタブを使いました。v1.17.0は自動ブラウザテストで生成した日本語一覧・設定・ポップアップ・取得進捗の画面を目視確認しています。これはユーザーのChromeへの拡張インストールの証明とは区別します。
- 公開されているNyaaのBootstrap・表用CSSと列構造を使い、架空の日本語タイトルで画面を構成しました。出典とライセンスは [fixture assets](https://github.com/came815/nyaa-enhancer-presets/blob/main/tests/fixtures/site-assets/README.md) にあります。実サイトの内容やユーザーの閲覧画面は同梱しません。

```

```

サーバーはループバック専用で、外部サイトの代理取得機能を持ちません。画像は自動テストの `test-results/` に生成されます。

## 未検証と制限

- 実サイトへのブラウザ操作は実行環境の自動安全判定で拒否されました。実サイトへの直接操作、現在の本番HTMLとの完全一致、他のインストール済み拡張との共存は未検証です。ローカル検証を実サイト検証の代用証明とはしていません。
- 実際のバックグラウンドタブでの停止・復帰は未検証です。自動操作用ブラウザは別タブを開いても表示中と判定したため、非表示判定の回帰テストでは `document.hidden` と `visibilitychange` の信号だけを模擬入力しています。ネットワーク取得・拡張コード・行の追加は実際のローカルブラウザで動かしています。
- 実サイトからのTorrentファイル取得、外部Torrentクライアントへの送信、外部メタデータAPIは今回実行していません。新しい取得・中止テストはローカルの架空ファイルだけを使用します。
- ユーザーのChromeプロファイルへの改造版インストール、Firefox、ミラーサイトは未検証です。
- 読み込み済み結果に対する絞り込みです。期間内の全件取得や、変動するシーダー数を厳密な同一時刻で比較したランキングを保証しません。
- 検索開始時刻はURLに保持されます。ページ読み込み後の時間経過だけでは自動で更新されません。更新（Refresh）またはプリセット再選択で更新してください。
