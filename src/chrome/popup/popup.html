How to use Torrent Client

+

🔒 About the permission prompt

The first time you click Test Connection, your browser will ask permission to access your torrent client's address. This is a browser security requirement: without it, the extension cannot reach a local or remote URL outside of Nyaa.

The permission is granted only for the exact host you entered (for example, your NAS or PC's IP) and is used solely to communicate with your torrent client. Nyaa Enhancer does not collect, transmit, or share any of your data.

  1. Select your torrent client from the Client dropdown below (qBittorrent, Transmission, or Deluge).
  2. Enter your client's URL (for example, http://192.168.1.100:8080).
  3. Optionally enter your credentials if the client requires authentication.
  4. For qBittorrent, open Options → Web UI in the WebUI and disable Enable Cross-Site Request Forgery (CSRF) protection. See the note below when qBittorrent is selected.
  5. Click Test Connection to verify everything is working, then click Save.
  6. On any Nyaa torrent page, use the Send button to send the torrent directly to your client.

Open the Settings pageand enable Show Send to Client Button. Otherwise, the Send button will not appear on Nyaa pages.

qBittorrent requirement

In qBittorrent WebUI, open Options → Web UI and disable Enable Cross-Site Request Forgery (CSRF) protection. If this stays enabled, sending a torrent to qBittorrent will fail.

⚠ If your server doesn't require authentication for local networks, leave the credentials fields blank.

Most settings and monitoring are available on the Settings page in the Nyaa navbar. This tab only contains API keys and credentials that must be configured here.
